# DESIGN_SYSTEM · 文件日报

## 产品视觉方向（2026-11-07 定）
**“文件档案室 / 案头日志”**：温暖纸感 + 深青主色，克制、可扫描、无装饰噪音。目标用户每天花 10–30 秒确认“今天各软件产出了什么”，因此首屏直接是“日期 + 当天清单”，不做仪表盘堆指标。

## 布局与信息层级（单页，最大内容宽 980px）
1. **顶栏**（sticky）：品牌图标+名称 ← 服务状态 pill（绿/琥珀/红 + 文案）· 刷新按钮（主操作，紧邻数据）· 设置。
2. **扫描进度条**：仅扫描期间出现在顶栏下方，琥珀色滚动条 + 文字（目录/文件/收录计数）。
3. **工具栏**：日期导航（‹ 大字日期+周几/今天标记 ›、原生日期输入、「今天」按钮）+ 右侧两组分段控件（新建|修改、按软件|按类型）+ 搜索框。窄窗口下分段控件换行。
4. **时间线 chips**：近 14 天横滚小卡（日期 + 当天文件数；今天带琥珀底线；选中态青绿描底）。
5. **统计条**：`n 个文件 · 总大小 · m 个分组` + 右端“共索引 N 个文件 · 上次扫描时间”。
6. **实时小结面板**（统计条下方，仅当天有文件时出现）：标题行「📋 实时小结」+ 副文案（新建/修改 n 个 · 大小 · 自动生成）+ 右侧主操作「🤖 AI 深度分析」；其下 4 张自动换行小卡（auto-fit ≥190px）：软件来源（名称+数量+大小+深青占比条）、内容构成（类型色点+占比条）、存放位置评估（问题 chips：绿=无异常/琥珀=提醒/红=告警）、管理能力（大分数+等级+计数注脚，等级三色）。面板底部分隔线下为 AI 结果区：加载态 spinner、完成态 markdown-lite 文本 +「模型 · 时间 · 截断/错误」元信息行。
7. **主清单**：分组卡片（色点 + 组名 + 数量/大小 + 折叠箭头），组内文件行：扩展名彩色徽章、文件名（主行）、完整路径（次行 ellipsis）、大小、时间、hover 出现的“📂 打开”。

## 主操作位置
- “刷新”常驻顶栏；“开始首次扫描”出现在首次空态卡片中央（primary）；“保存目录与规则”固定在抽屉底栏。

## 颜色角色（CSS 变量）
- 纸底 `#f4f1ea`、面板 `#fbf9f4`、墨色文字 `#26312e`、弱文字 `#6d7a74`。
- 主色深青 `#0f6e62`（选中/主按钮），今日强调琥珀 `#c47b12`，危险 `#b3423c`，服务正常绿 `#2f8e5b`。
- 分类固定色板（文档蓝灰/图片紫/视频红/音频绿/压缩棕/代码灰蓝/安装包紫罗兰/其他灰）——徽章背景 + 按类型分组色点，颜色承载语义但不做唯一标识（同时有文字标签）。

## 字体与间距
- 系统字体栈（system-ui / Segoe UI / 微软雅黑），基准 15px；日期大字 21px，组标题 14.5px，路径 11.5px。
- 间距 4 的倍数；卡片圆角 10px、行内 8px；阴影极浅两档。

## 组件与交互状态
- 按钮：default/primary/hover/disabled（刷新在未连接时禁用）；焦点可见 outline 2px 青。
- 分组头：可点击/键盘 Enter/Space 折叠展开，`aria-expanded` 同步。
- 空态：首次扫描引导（说明“只读属性不读内容”）、无文件日（提供 看前一天/增量刷新 行动）、搜索无结果。
- 错误态：服务未连接卡片带重试；toast 红底显示 API 错误原文；扫描超时以告警 toast + scanError 字段展示。
- 加载：清单“加载中…”卡片；扫描进度条文字持续更新。
- 键盘：←/→ 翻日期（输入控件聚焦时不劫持）；Esc 关抽屉。

## 窄窗口策略（≤720px）
工具栏换行、搜索框变窄、路径次行隐藏（title 提示保留完整内容）、日期字号收缩。最小支持 ~700×560 不出现横向溢出。

## 文案语言
全中文界面；技术词（token/API）不出现在界面。软件归属显示名用用户可编辑的 label。
